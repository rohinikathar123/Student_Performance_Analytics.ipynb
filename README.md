# Student Performance Analytics System

## 📌 Project Overview
The Student Performance Analytics System is a Python-based data analytics and machine learning project developed using Google Colab. It analyzes student academic performance based on study hours, attendance, assignment completion, previous scores, and other factors.

The project uses data visualization and a Random Forest classification model to explore student performance patterns and predict performance categories.

## 🎯 Objectives
- Analyze student academic performance.
- Calculate average marks and pass percentage.
- Visualize subject-wise scores and attendance patterns.
- Identify students who may need additional academic support.
- Predict student performance categories using Machine Learning.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## ✨ Key Features
- Synthetic dataset generation for 500 students.
- Data cleaning and exploratory data analysis (EDA).
- KPI calculation and performance summaries.
- Subject-wise marks visualization.
- Attendance vs. average marks analysis.
- Correlation heatmap.
- Random Forest classification model.
- Confusion matrix and classification report.
- Feature importance visualization.
- Student performance prediction.
- CSV report export.

## 📊 Machine Learning
**Algorithm:** Random Forest Classifier

**Target Variable:** Performance Category (Low, Medium, High)

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The model is evaluated on a separate test dataset.

## 🚀 How to Run the Project
1. Open the notebook in Google Colab.
2. Run each code cell in sequence.
3. Explore the dataset and visualizations.
4. Train and evaluate the machine learning model.
5. Enter sample student details to generate a prediction.
6. Download the generated CSV reports.

## 📁 Project Files
- `Student_Performance_Analytics.ipynb` — Complete Python notebook.
- `student_performance_dataset.csv` — Generated student dataset.
- `feature_importance.csv` — Model feature importance report.
- `model_predictions.csv` — Actual and predicted categories for test records.
